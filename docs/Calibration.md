# 权重自动校准方案

## 1. 目标

根据真实用户数据持续优化题目权重，提高测试稳定性。

## 2. 校准对象

- 问题权重
- 维度相关性
- 题目难度

## 3. 基础流程

```
收集匿名答题数据
↓
计算题目统计指标
↓
分析区分度
↓
调整权重
↓
发布新版本
```

## 4. 关键指标

### 区分度

判断问题是否能区分不同价值倾向。

### 一致性

检查同一维度问题是否产生相近结果。

### 相关性

分析问题与目标维度的关联程度。

## 5. 权重调整

建议保留人工审核。

自动算法提供建议：

```json
{
  "question_id": "Q00001",
  "old_weight": -5,
  "suggested_weight": -4,
  "confidence": 0.82
}
```

## 6. 发布机制

采用版本化：

```
question_bank_v1
question_bank_v2
```

保证历史结果可追溯。
