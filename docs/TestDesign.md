# 测试流程设计

## 1. 流程概览

```
开始测试
 ↓
生成测试会话
 ↓
分层随机抽题
 ↓
用户回答 Y/N
 ↓
计算维度分数
 ↓
分析一致性
 ↓
生成结果
```

## 2. 测试会话

每次测试生成独立 session：

```json
{
  "session_id": "xxx",
  "question_count": 40,
  "dimensions": ["privacy", "freedom"]
}
```

## 3. 答题阶段

要求：

- 不允许修改已提交答案（可配置）
- 记录答题时间
- 保存题目版本

## 4. 组卷策略

测试长度决定维度覆盖数量：

短测试：核心维度覆盖

完整测试：全部维度覆盖

## 5. 结果阶段

生成：

- 维度画像
- 高低倾向解释
- 价值冲突分析
- 置信度

## 6. 后续扩展

支持：

- 多语言题库
- A/B测试题目
- 动态调整题目难度
