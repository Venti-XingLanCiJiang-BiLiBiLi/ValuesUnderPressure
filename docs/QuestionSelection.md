# 随机组卷算法设计

## 1. 目标

随机生成不同测试卷，同时保证不同用户结果可比较。

## 2. 禁止方式

禁止：

```
从全部题目随机抽 N 题
```

原因：

- 可能缺失重要维度
- 不同用户测量目标不同

## 3. 分层抽题

流程：

```
选择测试长度
↓
确定维度配额
↓
每个维度随机抽题
↓
检查重复和覆盖
↓
生成测试卷
```

## 4. 题目池要求

每个维度应拥有多个同权重不同情境的问题。

例如：

```
privacy -5
├── 健康记录公开
├── DNA出售
├── 私密聊天公开
└── 记忆读取
```

## 5. 后续优化

根据用户数据调整：

- 题目出现频率
- 区分度
- 权重准确性
